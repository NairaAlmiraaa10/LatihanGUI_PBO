## ✨ Deskripsi Program

Program ini merupakan aplikasi GUI sederhana berbasis Java Swing yang digunakan untuk membuat form biodata mahasiswa. Pengguna dapat memasukkan Nama, NIM, dan Program Studi melalui kolom yang tersedia.

Program ini memiliki dua tombol utama, yaitu **Simpan** untuk menampilkan biodata yang telah dimasukkan dan **Hapus** untuk mengosongkan seluruh kolom input.

---

## 🧩 Komponen Utama GUI

Berikut adalah 5 komponen utama GUI yang digunakan dalam program ini:

| **Komponen** | **Class/Interface** | **Fungsi** |
|---|---|---|
| JFrame | Class | Membuat jendela utama aplikasi sebagai tempat menampilkan seluruh komponen GUI. |
| JPanel | Class | Menampung dan mengatur tata letak komponen GUI agar tersusun dengan rapi. |
| JLabel | Class | Menampilkan teks atau keterangan seperti Nama, NIM, dan Program Studi. |
| JTextField | Class | Menyediakan kolom input untuk memasukkan data mahasiswa. |
| JButton | Class | Membuat tombol Simpan dan Hapus untuk menjalankan perintah tertentu. |

### Tambahan: Event Handling

Program ini juga menggunakan **ActionListener (Interface)** untuk menangani aksi ketika pengguna menekan tombol. Ketika tombol Simpan diklik, program akan menampilkan biodata melalui `JOptionPane`, sedangkan tombol Hapus digunakan untuk mengosongkan seluruh kolom input.

## ⚙️ Teknologi yang Digunakan

- **Java** – Bahasa pemrograman yang digunakan.
- **Java Swing** – Library untuk membangun antarmuka grafis.
- **AWT** – Digunakan untuk mengatur tata letak komponen dan menangani event.
- **Visual Studio Code** – Editor untuk menulis dan menjalankan program.

---

## 🚀 Cara Menjalankan Program

1. Pastikan Java Development Kit (JDK) sudah terinstal.
2. Buka folder program menggunakan Visual Studio Code.
3. Buka terminal pada folder program.
4. Kompilasi program dengan perintah:

   ```bash
   javac LatihanGui.java
   ```

5. Jalankan program dengan perintah:

   ```bash
   java LatihanGui
   ```

6. Form Biodata Mahasiswa akan muncul dan siap digunakan.
